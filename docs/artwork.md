# Workshop artwork

Asset: `dist/assets/workshop.png`.
Created using the built-in image generation tool on 2026-10-28. The user selected Pixel Workshop (concept 2) before implementation. The generated illustration is decorative; active arcade rendering uses code-native canvas sprites and scenery.

Prompt used: preserve the approved warm, detailed 16-bit pixel-art maker workshop in terracotta, cream, teal, dark ink and ochre; afternoon light through a left window, pegboard tools, drawers, shelves, central green workbench with blue-and-orange wheeled robot, student mechanic, plants and tiled floor. Expand the workshop scene to a full-bleed landscape 16:10 composition. Remove the mockup's header, footer, side panel, buttons, labels, outlines and all typography. Keep central robot positioning for interactive HTML hotspots, crisp pixel textures, consistent isometric perspective and sun patches. No baked-in UI or physical-screen mockup.

The initial concept image is retained in the session-generated image store. Final project asset is self-contained in this repository. Font: Silkscreen from the official Google Fonts repository, bundled with its OFL license in `dist/assets/FONT-LICENSE.txt`.
